# -
以 STM32F103C8T6 为主控，基于 FreeRTOS 构建微型四轴飞行控制系统，实现姿态解算、无线通信与低频电源管理等任务的并发调度。集成 MPU6050 六轴传感器，采用一阶低通滤波与卡尔曼滤波对原始数据降噪，并基于四元数算法完成实时姿态解算，有效抑制高频振动环境下的传感器噪声与姿态漂移。设计并调试角度-角速度串级 PID 控制算法：内环角速度控制提升系统动态响应，外环角度控制保证姿态平稳；针对偏航轴 Yaw 设计独立限幅与补偿策略。基于 SI24R1 自定义无线双向通信协议，设计三段式状态机解锁逻辑与多重数据校验机制；实现通信失联保护逻辑，在信号中断时触发 fail-safe，使电机平缓减速降落，提高飞行安全性。
